# Sample CSVs for desktop testing

## Best test file (WeMoney-style)

[`wemoney-all-accounts-june.csv`](wemoney-all-accounts-june.csv) — **one file, many accounts**.

1. More → Accounts → **Add my 9 accounts**
2. More → Import CSV → drop `wemoney-all-accounts-june.csv`
3. Confirm the **Account** column is mapped to Account
4. Check each WeMoney name is matched to your ledger account (auto-suggested)
5. Commit → open Ledger / Transfers

# Redesign budget shortfall as guided coaching

Budget currently leads with "BUDGET SHORTFALL −$X" in red before any explanation. Logic is smart; presentation reads as alarm, not guidance.

## Acceptance criteria
- Shortfall is explained: what's driving it, what to do about it.
- Presentation feels like coaching, not a bare red alert.
- Underlying shortfall math (commitments + savings vs verified income) preserved.
